# ctrlsuite-downloads
CTRLSuite - A Controller Suite to manage all your joystick's needs

A tool initially born to adjust the Controller Deadzone, while I was developing I tried to make it a real hub to have all in one place all the tools one person can need to tune the joystick.
You may need some downloads separately to use the tool to it's full potential like HIDUSBF. If you don't you'll be able to still use to program except the overclocking feature.
